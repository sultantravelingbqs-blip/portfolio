M. ASAD — PERSONAL PORTFOLIO
============================

FILES
-----
index.html   Main portfolio webpage
style.css    Responsive styling, visual effects and animations
script.js    JavaScript interactions (mobile menu, typing text, scroll effects)

HOW TO OPEN
-----------
1. Extract the ZIP file.
2. Keep index.html, style.css and script.js together in the same folder.
3. Double-click index.html to open the portfolio in Chrome, Edge or Firefox.

HOW TO EDIT
-----------
- Open index.html to edit your name, education, location, and written content.
- Open style.css to change colors, spacing, fonts, and animations.
- Open script.js to change the typing phrases and interactive behavior.

NOTES
-----
- The JavaScript file for a website is named script.js. Java and JavaScript are
  different programming languages; this portfolio uses JavaScript in the browser.
- The skill bars are decorative design elements, not measured skill ratings.
- Portfolio cards are clearly labeled as practice ideas, not completed projects.
- Google Fonts are loaded online. The page still works without them, using
  fallback fonts.
