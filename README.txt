M. ASAD — CREATIVE PORTFOLIO
============================

WHAT'S INCLUDED
---------------
index.html   Portfolio content and page structure
style.css    Responsive red / charcoal / warm beige design
script.js    Mobile navigation and scroll progress

HOW TO VIEW
-----------
1. Extract the ZIP file.
2. Keep index.html, style.css and script.js together in one folder.
3. Open index.html in Chrome, Edge or Firefox.

ABOUT THIS VERSION
------------------
The visual direction follows the supplied reference: oversized editorial
lettering, a red hero, an angled charcoal navigation band, warm beige content,
and a dark lower-contrast visual rhythm.

The supplied portfolio archive contained no personal portrait, email address,
social links, or finished project screenshots. The hero therefore uses an
original MA monogram illustration instead of pretending a stock image is you.
The three portfolio cards are clearly marked as practice concepts, not finished
client work. The content preserves the education, location, learning interests
and project descriptions in the supplied original portfolio.

HOW TO PERSONALIZE FURTHER
--------------------------
- To add a portrait, replace the MA monogram artwork inside the .hero-art
  element in index.html with your own image, then add image styling in style.css.
- To add real projects, replace the three practice-concept cards in index.html
  with project screenshots, names, descriptions and working links.
- To add contact details, add your preferred email or social profile links in
  the contact section of index.html.
- Edit the biography and skills in index.html whenever your information changes.

NOTES
-----
Google Fonts are loaded online. If there is no internet connection, fallback
fonts are used. The site uses plain HTML, CSS and JavaScript; no build tools or
installation are required.
